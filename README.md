Spotify Dataset Analysis – Milestone 1 CIE

Project Overview

This project analyzes a Spotify dataset using Python to understand music data, perform data transformation, handle missing values, generate insights and visualize results.

Dataset Details

- Records: 20,594
- Original Columns: 24
- Format: CSV

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Tasks Performed

1. Dataset selection and reading using Pandas.
2. Data understanding and exploration.
3. Data transformation and column standardization.
4. Missing value identification and imputation wherever applicable.
5. Insight generation.
6. Data visualization using charts.

Files Included

- "Milestone1.ipynb" – Python notebook.
- "cleaned_dataset.csv" – Cleaned dataset.
- "README.md" – Project documentation.

Conclusion

This project demonstrates practical data analysis, preprocessing, insight generation and visualization using Python libraries.
